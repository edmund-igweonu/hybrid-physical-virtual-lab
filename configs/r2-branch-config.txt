# R2-BRANCH — FRRouting 8.2.2 (Linux/Alpine appliance)

## Linux interface config (WAN + branch LAN)

ip link set eth1 up
ip addr add 192.168.100.2/30 dev eth1

ip link set eth2 up
ip addr add 10.20.10.1/24 dev eth2

## FRR / vtysh OSPF config

router ospf
 network 192.168.100.0/30 area 0
 network 10.20.10.0/24 area 0
exit

## VPCS branch client config

ip 10.20.10.10/24 10.20.10.1

## Verification commands used

show ip ospf neighbor
show interfaces brief
ping 10.10.10.1     # reachability to HQ VLAN 10 gateway via OSPF
ping 192.168.100.1  # WAN link to R1
