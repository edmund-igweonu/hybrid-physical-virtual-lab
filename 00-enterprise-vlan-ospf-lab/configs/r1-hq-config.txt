# R1-HQ — FRRouting 8.2.2 (Linux/Alpine appliance)

## Linux interface config (VLAN subinterfaces + WAN)

ip link set eth0 up
ip link add link eth0 name eth0.10 type vlan id 10
ip link add link eth0 name eth0.20 type vlan id 20
ip link add link eth0 name eth0.30 type vlan id 30
ip link set eth0.10 up
ip link set eth0.20 up
ip link set eth0.30 up

ip addr add 10.10.10.1/24 dev eth0.10
ip addr add 10.10.20.1/24 dev eth0.20
ip addr add 10.10.30.1/24 dev eth0.30

ip link set eth1 up
ip addr add 192.168.100.1/30 dev eth1

## FRR / vtysh OSPF config

router ospf
 network 10.10.10.0/24 area 0
 network 10.10.20.0/24 area 0
 network 10.10.30.0/24 area 0
 network 192.168.100.0/30 area 0
exit

## Verification commands used

show interfaces brief
ip addr show eth0.10
ip addr show eth0.20
ip addr show eth0.30
show ip ospf neighbor
show ip route ospf
